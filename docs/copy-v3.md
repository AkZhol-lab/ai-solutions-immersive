  100, правило «только transform / opacity» — PASS.

## Изменения в общем коде (на основной сайт не влияют)

- `src/webgl`: униформа `uChaos` и затемнение `dim` — при 0 (всегда на основном сайте) ничего
  не меняют. Положение финальной точки считается от конца страницы — для экранной CTA это то же
  самое, что раньше; для высокой CTA точка остаётся на экране.
- `src/core/scroll.ts`: `bindSegment` по тому же индексу заменяет прежний диапазон; облака
  кластеров берут центры из «источников» (тарифы — один источник, как раньше; v3 добавляет роли).
- `scripts/screens.mjs`: `--query`, сцены v3 (пропускаются, если их нет на странице), проверка
  текстов v3.

## Решить перед внедрением

1. **Показывать ли цены** — вы скажете отдельно. v3 тарифы и цены не трогает; FAQ про стоимость
   написан так, что верен в обоих случаях.
2. **Демо-цена «от 15 000 ₸»** — условная, с пометкой. Можно заменить на любую из вашего прайса
   или убрать цену из демо совсем.
3. **Подводка CTA.** В v3 — «пара уточняющих вопросов → короткий созвон» вместо «в ответ — разбор»
   из текущего сайта. Это мягче по обещанию; если хотите оставить «разбор», верну.
4. **«Астана» в шапке** скрыта в v3 (есть в бейдже). Если нужна в обоих местах — верну.
